# API/UI Demo 分层规范

## simple_api

```text
Tests → Fixture → Factory + Repository → 公共 HTTP 客户端
```

只演示少量 HTTP Case，不引入 Feature、Steps 和大型业务编排。

## bdd_api

```text
Feature → Steps → Data Factory → Repositories → 公共协议客户端
```

Feature 使用中文 Gherkin；步骤传递结构化 `api_response`，断言统一复用 `core/dal`。

## pytest_api

```text
Tests → Services/Workflows → Data Factory → Repositories → 公共协议客户端
```

测试函数只调用公开业务对象，不直接操作协议客户端私有字段。

## bdd_ui

```text
Feature → Steps → Fixture 装配 → 公共产品 Flow + Data Factory
        → 公共产品 Page Object / Repository → SyncWebRuntime
```

## pytest_ui

```text
Tests → Fixture 装配 → 公共产品 Flow + Data Factory
      → 公共产品 Page Object / Repository → SyncWebRuntime
```

UI 元素统一由 `core/sources` 加载，由 `core/ui` 转换并执行；同一产品的 Page Object、Flow、Repository 和能力执行器放在 `auto_tests/common/<product>/`。

完整强制规则以仓库根 `AGENTS.md` 为准。
